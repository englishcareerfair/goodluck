# HARD RULE: Sequential Number Commit Naming

All git commits in this repository MUST be named strictly using sequential integers.

- The sequence ended at commit 19 (`78fb831`).
- The current commit MUST be `20`.
- All subsequent commits MUST be `21`, `22`, `23`, etc.
- NEVER use conventional commits (e.g. `feat: ...`, `fix: ...`) or text summaries as the commit message.
- Always run `git commit -m "<N>"` where `<N>` is the next sequential integer.
